# ADR-004: Desain capability-first

- Status: Diterima
- Tanggal: 2026-09-16

## Konteks

Menganggap setiap kebutuhan sebagai agent meningkatkan biaya, risiko, dan kompleksitas operasional.

## Keputusan

Modelkan kapabilitas yang dibutuhkan terlebih dahulu, kemudian pilih workflow, rule, tool, skill, agent, atau human process sebagai delivery mode.

## Konsekuensi

Pembuatan agent memerlukan alasan eksplisit; kapabilitas deterministik yang sederhana tetap dibuat sederhana.
